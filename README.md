# Curtis BCH 0.1.10

Miners UI redesign.

- Removes Donut-O-Meter / glaze / RNG gimmick presentation.
- Rebuilds each worker as a clean responsive mining card.
- Highlights hashrate, best/record, network target, record progress, odds, status, and last share.
- Adds a clear graphical record-progress bar.
- Keeps per-worker reset behavior.
- Adds active/inactive badges and a manual Refresh Now button.
- Adds a compact About Best Shares explanation.
- No mining backend, BCHN, CKPool, Testnet4, payout, or difficulty behavior changed from 0.1.9.

This release is intentionally frontend-focused.
